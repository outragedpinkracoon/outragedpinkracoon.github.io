OUTRAGED PINK RACOON — STANDALONE WEBSITE

Open index.html in your browser. The Photography link opens the gallery.
No Jekyll, Ruby, package installation or build step is required.

Contents
  index.html                Homepage
  photography/index.html    All 58 photographs; autumn lake opens the gallery
  assets/css/main.css       Shared styles and homepage design
  assets/css/photography.css Gallery styles
  assets/js/photography.js   Large-image viewer and keyboard controls
  assets/photos/            Web-sized JPEGs in two sizes

Keep this folder structure intact. Paths are relative, so the site also works
from a subdirectory. Upload the folder contents to a static web host to publish.

Click a photograph to open it large. Arrow keys navigate; Escape closes it.
The homepage destinations are ordinary links in index.html.
The copyright year is static in this standalone export.

Your original source photographs are not included or modified.
